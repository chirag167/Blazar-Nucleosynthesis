Cloud reaction network

Each square is a nucleus in the network, placed by proton number (Z) and neutron number (N) and shaded by its abundance. Select one to see which reactions make it and which destroy it, ranked by how fast each one runs right now.

How the ranking works. Thermonuclear and decay rates are evaluated at the snapshot above: each reaction's events per second times how many of the nucleus it makes or uses up, in units of Y/H per second. The share bar is that reaction's fraction of all production (or all destruction) of the nucleus.

Jet-cloud reactions depend on the jet's energy spectrum, so they are listed but not ranked. Only reactions with a jet projectile (p or α) run in the current code; reactions whose projectile is a secondary product are in the library but not followed.
